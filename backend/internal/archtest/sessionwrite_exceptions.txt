# Functions in internal/play and internal/maps (non-test) that open a transaction which writes (INSERT, UPDATE or DELETE of the package's own queries) outside the funnel (Service.tx, Service.txOn).
# One entry per line, sorted: "package file function" ("(*T).Method" for a method). The reason after # starts with the area of the #735 plan.
# Two sections, told apart by the reason:
#   work queue: any reason but "permanent:". Areas: 4b, 4c, 4d (play), 4d maps, session lifecycle, characters host (task B).
#     The queue can only shrink: convert the writer to Service.tx and delete its line.
#   permanent: "# permanent: <reason>" is accepted forever, because the function never touches what a live session shows. It is still listed,
#     so that a new writer is noticed, and it is stale like any entry when it stops being an offender.
# An entry sits on the callee. Converting it can need the calling module to change too (characters, progression call into play with their own transaction).
# A line whose function is no longer an offender fails the test.
