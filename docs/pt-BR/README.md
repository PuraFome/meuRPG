# Documentação do MeuRPG (português)

> O inglês é o idioma canônico; esta pasta traz as versões em português dos documentos para quem lê o produto: o [README](../../README.pt-BR.md), a visão, as histórias, as regras, o glossário e a privacidade. A documentação de engenharia (arquitetura, dados, design, operação, roadmap, CONTRIBUTING) é só em inglês: ver o [índice completo](../README.md).

**Fase atual: pré-MVP.** Tudo o que estava planejado para o MVP está construído; antes da primeira sessão de verdade da mesa vêm o endurecimento e um ensaio, depois a internacionalização e as histórias pós-MVP (ver o [roadmap](../roadmap.md)).

## Como manter estes documentos

Quando uma versão em inglês muda, a versão em português muda no mesmo PR (a regra está em [CONTRIBUTING.md](../../CONTRIBUTING.md#how-to-keep-the-docs-current)). A estrutura, os títulos e os ids (RN-xx, MR-xx) são os mesmos nas duas línguas. O texto da interface continua em português até a internacionalização.
